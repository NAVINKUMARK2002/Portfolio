# Communication trainer portfolio

Editable, buildless HTML/CSS portfolio. Update `index.html` for content and `assets/css/styles.css` for the design.

## Preview

Run `python -m http.server 8000 --bind 127.0.0.1` and open http://localhost:8000.

## Content to complete

- Replace YOUR NAME in the header, footer, and page title.
- Replace the clearly labeled sample employment dates (2024?Present, 2022?2024, 2020?2022) with confirmed dates. Current-role status is also sample data.
- Add personal contact details, a photo, and CV when supplied.

The page uses the supplied trainer content. No previous owner's identity, references, certificates, contact information, or backend is used by the active portfolio. Google Fonts is optional; system fonts work offline.

The previous downloaded site and its assets are retained under `archive/original-site/` for reference only. They contain the previous owner's information and are not linked by the new page. Exclude the archive when publishing this portfolio.

The hero now uses `assets/images/portrait-placeholder.jpg`, copied from the original design at your request. This is a clearly labeled temporary image; replace it with your own portrait before publishing.
